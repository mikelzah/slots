# АМС-КОМПЛЕКС · Игровой модуль

Статическое приложение: HTML, CSS и JavaScript, без сборки и зависимостей для локальных игр.

## Локальный запуск

Нужен Node.js 24 или новее:

```sh
node dev-server.cjs
```

Открыть `http://127.0.0.1:8765/index.html`. Файлы нужно открывать через HTTP: ES-модули и загрузка экранов не работают через `file://`.

## Навигация и состояние

`index.html#slot`, `#durak`, `#checkers`, `#minesweeper`, `#doom`, `#achievements`, `#profile` открываются в одном документе. Прямые старые ссылки вида `checkers.html` тоже работают и переводятся на основной адрес.

`app.js` управляет маршрутизацией и кэшем экранов. Игры инициализируются из ES-модулей, их переменные изолированы. `lifecycle.js` приостанавливает таймеры, анимацию и глобальный ввод неактивных игр. Партии сохраняются при переходах до обновления или закрытия страницы. Статистика, достижения, баланс и профиль хранятся в браузере.

`ui.css` задаёт общую корпоративную тему. Эталон — Дурак: одинаковая ширина контейнеров, игровая область 480 px по высоте на компьютере и 420 px на узком экране. Квадратные доски вписаны внутрь; большие поля прокручиваются.

## Профиль

Имя и цвет аватара сохраняются локально под ключом `amsProfile`. Профиль не является авторизацией, не создаёт аккаунт и не синхронизируется между устройствами. В нём показаны суммарные партии, победы и достижения.

## Проверки

```sh
node --test tests/minesweeper.test.js tests/profile.test.js tests/lifecycle.test.mjs
```

Для среды с ограничением дочерних процессов:

```sh
node --test --test-isolation=none tests/minesweeper.test.js tests/profile.test.js tests/lifecycle.test.mjs
```

Проверяются правила Сапёра, сохранение профиля, пауза таймеров и анимации, отключение ввода неактивной игры, отмена отложенных ходов при перезапуске.

## Онлайн-режим и публикация

Онлайн-Дурак использует существующую конфигурацию Firebase и внешний SDK. Если SDK или соединение недоступны, локальные игры остаются доступны. Проверен сценарий двух клиентов: создание комнаты, вход по коду, атака, защита, «Бито», переход в другую игру и возврат, выход обоих игроков. Серверная конфигурация и правила Firebase в этом изменении не менялись.

Формы платежей и корпоративные модули — демонстрационные. Они не выполняют реальные переводы и не оформляют подписку.

Публикация выполняется существующим workflow GitHub Pages при обновлении ветки `claude/slots-simulator-github-pages-2dvcb7`. Кандидат редизайна подготовлен локально в ветке `design/corporate-release`; не отправлять его в ветку публикации без согласования.
